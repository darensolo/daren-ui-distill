# Contributing

Thanks for helping improve UI Distiller.

1. Open an issue before making a large contract or architecture change.
2. Keep the six production stages and registration/publication receipts explicit.
3. Never include credentials, private sessions, unrelated user files, or UI evidence without redistribution rights.
4. Run `pnpm install --frozen-lockfile` and `pnpm test` before submitting a pull request.

Bug fixes and documentation improvements can go directly to a focused pull request. Public contract changes require a compatibility note and affected-consumer tests.
