# Self Improvement Loop

Design Asset Registrar may learn from execution, but it must not rewrite itself automatically.

## Every Run Produces

Workflow retrospective evidence:

- What worked.
- Workflow gaps.
- Missing references, adapters, or checks.
- Proposed skill updates.
- Risk if unchanged.

## Routing

- Asset-specific issues go to the gap report.
- Generic workflow, adapter, benchmark, approval, or script issues become `skill-improvement-proposal`.

## Write Rule

Do not modify Design Asset Registrar skill files without explicit user confirmation. If the user approves a skill update, use normal patch flow or a skill creation/update workflow.
